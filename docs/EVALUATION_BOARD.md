# AcademicCheck AI Evaluation Board — dataset audits

Date: 2026-09-07  
Status: **Phase 1 schema/documentation audit only.**  
Records sampled from disk: AcademicCheck internal files only.  
Public corpora (ASAP, TOEFL11, PERSUADE, AAE): **not downloaded in this workspace.** They are **not declared gold.**

Rule: a dataset is production-grade gold only after (a) lawful access, (b) 100–300 human-reviewed records per selected split, (c) documented dual annotation onto AcademicCheck label inventories, (d) frozen held-out IDs.

This work is evaluation architecture. It does not add student-facing product features.

---

## Label inventories that gold must match

| Analyzer | AcademicCheck labels | What is not a match |
| --- | --- | --- |
| Thesis | `strong` / `weak` / `missing` (implicit and multiple theses are test conditions, not extra classes) | Holistic essay score; L1; “Position” span without quality class |
| Argument | reasoned vs descriptive; flags for claim, reasoning, counter, rebuttal, gap | Discourse-type spans without a mapping protocol |
| Evidence | `supported` / `needs_citation` / `potentially_unsupported` / `cannot_determine` | “Evidence” rhetorical span; no citation-need class |
| Rubric | criterion names covered when mapped diagnostic ≥ 55 | AES holistic 1–6; trait scores for content/organization/style |

## Audit A — ASAP (Hewlett / Kaggle AES)

**Name:** Automated Student Assessment Prize essay set  
**Description:** ~12,970 essays, 8 prompts, US grades ~7–10. Dual human scores; most prompts holistic; prompts 7–8 trait scores; ASAP++ adds traits for 1–6.  
**Schema (typical):** `essay_id`, `essay_set`, `essay`, `rater1_domain1`, `rater2_domain1`, `domain1_score` (+ optional domain2 / traits).  
**Labels:** resolved holistic (and some traits). **No thesis/argument/evidence span labels.**  
**Metadata:** prompt-specific rubrics; two raters; quadratic weighted kappa used historically.  
**Sample records:** not in repo. Not reviewed.

| Dimension | Score | Rationale |
| --- | ---: | --- |
| Dataset quality | 78 | Operational dual scoring; public; prompt heterogeneity and anonymization artifacts (`@CAPS`, etc.) are known |
| Academic relevance | 28 | Secondary school; not UG/PG/Masters/PhD assignment writing |
| Thesis coverage | 12 | No strong/weak/missing; some argumentative prompts only |
| Argument coverage | 15 | No claims/counters/rebuttals |
| Evidence coverage | 14 | No citation-need / unsupported taxonomy |
| Rubric coverage | 48 | Prompt rubrics exist; they are AES traits, not AcademicCheck criterion-mapping |

**Board decision: REJECT as gold for thesis, argument, evidence.**  
**Conditional candidate (research only) for rubric:** correlation studies between ASAP trait/holistic scores and AcademicCheck diagnostics — **after** 200-record human review. Do not train or certify `rubric_covered()` on ASAP labels.

**F1 impact if used raw:** near-zero validity. Mapping holistic high score → “strong thesis” will **inflate** apparent thesis F1 on argumentative prompts and **hide** missing-thesis errors.

## Audit B — TOEFL11 (ETS / LDC)

**Name:** ETS Corpus of Non-Native Written English (TOEFL11)  
**Description:** 12,100 TOEFL essays; 1,100 per 11 L1s; 8 prompts; score level low/medium/high. Built for **native language identification**.  
**Schema:** essay text, L1, prompt, proficiency band.  
**Labels:** L1 + 3-way proficiency. **None of the four AcademicCheck inventories.**  
**Metadata:** LDC license; not freely redistributable.  
**Sample records:** not in repo.

| Dimension | Score | Rationale |
| --- | ---: | --- |
| Dataset quality | 82 | Operational ETS collection; balanced L1×prompt by design |
| Academic relevance | 42 | High-stakes EAP / college-entrance; not discipline dissertations; useful ESL range only |
| Thesis coverage | 8 | Unlabeled |
| Argument coverage | 8 | Unlabeled |
| Evidence coverage | 8 | Unlabeled |
| Rubric coverage | 18 | Coarse proficiency band ≠ criterion mapping |

**Board decision: REJECT for thesis, argument, evidence, and rubric gold.**  
May later support **language-proficiency stress tests** (separate from the four analyzers) if licensed. Not a substitute for lecturer gold.

**F1 impact if used raw:** undefined. Any derived labels would be circular if generated by AcademicCheck itself.

## Audit C — PERSUADE 2.0 (Learning Agency / Vanderbilt)

**Name:** PERSUADE 2.0  
**Description:** ~25,992 US grade 6–12 argumentative essays; 15 prompts; independent and source-based; discourse spans + holistic 1–6; demographics.  
**Schema:** `essay_id`, `full_text`, `holistic_essay_score`, `word_count`, `prompt_name`, `task`, plus span table: `discourse_start/end`, `discourse_text`, `discourse_type` ∈ {Lead, Position, Claim, Counterclaim, Rebuttal, Evidence, Concluding Statement, Unannotated}; effectiveness Ineffective/Adequate/Effective (~4% / ~79% / ~17%).  
**Annotation:** double-blind expert rating with 100% adjudication (publisher documentation).  
**License:** CC BY-NC-SA 4.0 on the common Kaggle mirror — **non-commercial share-alike. Production commercial use is not assumed permitted.**  
**Sample records:** not in repo. Span quality unverified here.

| Dimension | Score | Rationale |
| --- | ---: | --- |
| Dataset quality | 84 | Large, documented, double-rated; effectiveness class imbalance is a defect |
| Academic relevance | 32 | Secondary school prompts (“distance learning”, facial coding, etc.), not university modules |
| Thesis coverage | 55 | `Position` ≈ explicit thesis span; weak/missing/implicit **not** native classes; effectiveness is a weak proxy |
| Argument coverage | 80 | Claim, Counterclaim, Rebuttal, Evidence spans are the strongest public match |
| Evidence coverage | 40 | Rhetorical “Evidence” ≠ `needs_citation` / fabricated-universal claims; source-based subset helps |
| Rubric coverage | 35 | Holistic 1–6 + element effectiveness; not AcademicCheck criterion names |

**Board decision:**

- **Argument evaluation: CONDITIONAL ACCEPT as a candidate**, not gold, pending license review + 300-record remapping onto AcademicCheck argument flags.
- **Thesis: CONDITIONAL ACCEPT as a candidate for explicit-position presence only**, not for strong/weak/missing.
- **Evidence / rubric: REJECT as native gold.**

**F1 impact if used without remapping:** argument detection F1 may look high on span-overlap of Claim/Evidence and **overstate** production quality, because AcademicCheck currently scores paragraph-level reasoned-vs-descriptive, not PERSUADE span types. Treating every Position as `strong` will **inflate** thesis F1.

## Audit D — AAE (Stab & Gurevych Argument Annotated Essays v2)

**Name:** Argument Annotated Essays (AAE 2.0)  
**Description:** 402 English persuasive essays (essayforum.com and related), annotated for Major Claim, Claim, Premise, support/attack, claim stance for/against.  
**IAA (published):** major claims κ ≈ 0.877; premises κ ≈ 0.833; **claims κ ≈ 0.635** (hardest). Relations substantial.  
**Schema:** component spans + relations (support/attack).  
**Sample records:** not in repo.

| Dimension | Score | Rationale |
| --- | ---: | --- |
| Dataset quality | 80 | Expert scheme, published IAA, small n, forum register, license “other” — must read TUD terms |
| Academic relevance | 45 | Often exam/IELTS-like persuasion; not UK/US module scripts with rubrics and citations |
| Thesis coverage | 62 | Major Claim ≈ explicit thesis; restatement in conclusion; weak/missing/implicit poorly represented |
| Argument coverage | 86 | Best public **structure** gold (claim–premise–attack) |
| Evidence coverage | 38 | Premises are reasons, not citation-supported facts |
| Rubric coverage | 10 | No assignment rubric |

**Board decision:**

- **Argument (relationship accuracy): CONDITIONAL ACCEPT as a candidate.**
- **Thesis: CONDITIONAL ACCEPT for explicit major-claim detection only.**
- **Evidence / rubric: REJECT as native gold.**

**F1 impact:** mapping Premise → `has_reasoned_argument=True` will **inflate** argument F1 on forum essays that always contain premises. Mapping Major Claim → `strong` will miss `weak` topic announcements that AAE may still tag as major claims.

## Audit E — AcademicCheck template gold (`eval.py` `*_gold()`)

**Name:** Internal circular template set  
**n:** question 4320, thesis 4032, argument 3648, evidence 2880, rubric 96, citation 55  
**Labels:** generated from the same regex/command inventories as the classifiers.  
**Sample:** inspected. Example: `This essay argues that {topic}` → `strong`.

| Dimension | Score | Rationale |
| --- | ---: | --- |
| Dataset quality | 40 | Complete and consistent **as templates**; circular by construction |
| Academic relevance | 25 | Topic strings are academic; texts are not student writing |
| Thesis coverage | 20 | Only marker phrases; not independent |
| Argument coverage | 18 | Marker phrases |
| Evidence coverage | 22 | Marker phrases |
| Rubric coverage | 15 | Alias dictionary, not lecturer rubrics |

**Board decision: REJECT for all validity, gold, and 98% claims.** Retain **only** as a regression canary for classifier-rule drift.

**F1 impact:** currently ~1.00. That is **consistency**, not correctness. Using it as training labels would lock the system to its own regexes.

## Audit F — AcademicCheck independent held-out (`heldout.py` + `heldout_extra.py`)

**Name:** Expert-constructed held-out  
**n:** thesis 20, argument 17, evidence 18, plus question/citation (not in this four-way brief). Dual lecturer file `reviewer_labels.jsonl` is **empty**.  
**Sample:** fully inspected (census, not 300). Covers strong/weak/missing, implicit contestable theses, counters (`however`/`although`), four-way evidence, several disciplines.

| Dimension | Score | Rationale |
| --- | ---: | --- |
| Dataset quality | 58 | Clean, consistent, no missing labels; single constructor; no dual κ; tiny n |
| Academic relevance | 72 | University command words and disciplines; still synthetic paragraphs, not submitted scripts |
| Thesis coverage | 70 | Explicit, implicit, weak, missing, multi-claim; n=20 |
| Argument coverage | 48 | Reasoned vs descriptive; counters present; rebuttal/relationship gold thin |
| Evidence coverage | 65 | All four classes present; n=18 |
| Rubric coverage | 5 | No independent rubric gold (96 circular only) |

**Board decision: ACCEPT as a frozen regression seed. REJECT as production gold and as 98% certification gold.**

**F1 impact:** point F1 1.00 with CI low 0.82–0.84. Expanding n with the same author **without** dual review will keep F1 high and **understate** real error.

## Training / evaluation / gold / regression architecture

```
[Forbidden train]  template *_gold()          → regression canary only
[Allowed train]    none until remapped public
                   or lecturer JSONL exists

[Eval-dev]         50% of remapped PERSUADE/AAE
                   after 100–300 human audit  → development, not launch 98

[Eval-test]        frozen remaining 50%
                   + AC held-out (never train)

[Gold benchmark]   reviewer_labels.jsonl
                   dual lecturer, n≥1000/analyzer
                   **empty today**

[Launch cert]      gold benchmark
                   + documented IAA
                   + public-set auxiliary report
                   (not F1 on PERSUADE spans)
```

### Training set recommendation

**Do not train AcademicCheck classifiers on any of these datasets yet.** The production analyzers are deterministic rules. Fine-tuning an LLM on PERSUADE/AAE/ASAP would change product behaviour and is out of scope. If a later model path exists: train only on remapped labels, never on template gold.

### Evaluation set recommendation

1. Keep AC held-out frozen.  
2. After license clearance, draw a stratified 300-essay PERSUADE sample (grade 11–12 only, both tasks) and 150 AAE essays; dual-map to AcademicCheck inventories; report disagreement.  
3. Do not compute launch F1 on unmapped public labels.

### Gold benchmark recommendation

**Not declared.** `reviewer_labels.jsonl` remains empty. Gold = dual academic raters on university assignments. Public datasets can **support** gold construction; they are not gold.

### Regression testing recommendation

Keep `test_ai_quality_gate.py` + template floors as **consistency** tests. Keep `test_ai_heldout.py` as **independent seed**. Add a future `test_ai_public_remap.py` only after the 100–300 review file exists on disk.

## Gate for “gold”

Auditors should trust, in this order:

1. Dual human labels in `reviewer_labels.jsonl` with κ.  
2. Human-reviewed 100–300 record samples of any public remap, with disagreement log.  
3. Public datasets (PERSUADE, AAE, ASAP) **as documented sources**, not as drop-in AcademicCheck F1.

TOEFL11 is trusted as an NLI corpus, not as AcademicCheck gold.

Until (1) exists, **do not certify 98%** on thesis, argument, evidence, or rubric.
